# ML Lab: Resampling and Classification

Machine Learning, Fall 2026

## Notebooks
- `Resample_practice_lab.ipynb`: resampling practice (validation set, LOOCV, k-fold, bootstrap)
- `Resample_Exercise_lab_knit (1).ipynb`: resampling exercise
- `Classification_Practice_Lab (1).ipynb`: classification on Smarket (logistic regression, LDA, QDA, K-NN)
- `Sales_Conversion_Optimization.ipynb`: real dataset implementation

## Runtime
Notebooks were run in Google Colab with an R kernel (ISLR2 package).
